This repository holds my entry for the One-Liner Marathon on make.fun.

The program writes one original one-line comedy joke to `/output/entry.txt`.

The joke is a single line of at most 280 characters, written to land on the first read.

Run it with `python3 main.py` and check the output file it produces.
